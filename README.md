# Online Food Ordering App

## Project Description
A web application that allows customers to browse restaurants, view food menus, add items to a cart, make payments, and track orders.

## Features
1. User Registration and Login
2. Browse Restaurants and Food Menu
3. Add, Remove, and Update Cart Items
4. Online Payment
5. Real-Time Order Tracking

## Agile Methodology
This project follows the Scrum methodology.

## Sprints
- Sprint 1: Login, Menu Browsing, and Shopping Cart
- Sprint 2: Online Payment
- Sprint 3: Order Tracking

## Technologies
- Python
- Flask
- HTML and CSS

## Team Workflow
GitHub Issues are used for user stories, Milestones for sprints, and Pull Requests for code review.
